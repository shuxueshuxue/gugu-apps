# Changelog

## 0.5.0

- 通过常驻指令主动记录收到的会话中的明确个人事项；明确行程直接记录，不再确认记录意图，缺少可选细节也不阻止记录。
- 新增查询与更新工具，支持完成、补充与改期。
- 按年、月、日拆分文件，旧数据迁移保留备份。
- 跨日改期支持中断恢复，月历只读取当月内容。
- 需要支持 contributes.agentInstructions 的咕咕版本；已运行会话需重新启动。

## 0.4.2

第一次上市场。任务页右侧栏里的日历：上面一个月，下面是选中那天的待办和记事；你自己在页面上加、勾、删，也可以让 agent 用 `record` 帮你记。

和 0.4.1 比：

- Windows 上，存的那一刻页面正好在读，也不会再「没存上」；
- 不存在的日期（比如 2 月 31 日）会被拒，不再记到一个页面上看不到的地方；
- 勾选或删除没存上时，页面回到文件里的样子，不再停在没存上的那个状态；
- 页面不在屏幕上时不去读；
- 英文界面下，翻月的两个按钮也说英文了；
- 补上了图标、作者和最低咕咕版本。

版本号升一位，已经装着 0.4.1 的人按同一个 id 收到这一版。
